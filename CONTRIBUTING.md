# Contributing

Thanks for helping improve `csv-quality`.

## Before opening an issue

- Remove personal, financial, health and customer data from every CSV example.
- Include the smallest anonymized input that reproduces the problem.
- Describe the delimiter, line endings and quoting pattern involved.
- Include the Node.js version and the exact CLI command when reporting a CLI problem.

## Pull requests

1. Keep the change focused on one behavior.
2. Add or update a test when parsing, analysis, reporting or CLI behavior changes.
3. Run `npm test`, `npm run typecheck` and `npm run build`.
4. Explain the user-visible result and any remaining limits.

Please do not submit real private data in issues, tests or fixtures.
